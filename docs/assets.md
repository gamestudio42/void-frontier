# Assets

Starfield, dust, planets, beacons, stations and the hulls without a studio mesh are procedural, generated by `packages/view3d`. There are no third-party models, textures, fonts or sounds.

Kestrel, Marauder, Bulwark and Dreadmaw are original GameStudio42 art, baked from `gamestudio42/assets/naves` (Blockbench mesh, atlas, ORM and glow). The game stores the bake, not the generator. Each directory under `packages/view3d/assets/<ship>/` has:

| File | What it is |
|---|---|
| `hull.json` | Centred mesh in model space (nose +X), plus nozzle points |
| `atlas.png` | Albedo, occlusion already multiplied in |
| `orm.png` | Roughness in G, metal in B |
| `glow.png` | Emissive glass, bells and lights |

| Ship | Studio mesh |
|---|---|
| Kestrel | `naves/interceptador` |
| Marauder | `naves/corveta` (corvette v2) |
| Bulwark | `naves/corveta_pesada` |
| Dreadmaw | `naves/dreadnought` |

Each mesh is scaled to `hull.length` at runtime. The collision circle stays in `packages/content/data/ships.json`. See decision 064.

When a third-party asset is added, list it here with its source, author, license and the files it covers.
