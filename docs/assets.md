# Assets

Starfield, dust, planets, beacons, stations and every hull except the Kestrel are procedural, generated by `packages/view3d`. There are no third-party models, textures, fonts or sounds.

The Kestrel's hull is original GameStudio42 art, baked from the interceptor in `gamestudio42/assets/naves/interceptador` (Blockbench mesh, atlas, ORM and glow). The game stores the bake, not the generator:

| File | What it is |
|---|---|
| `packages/view3d/assets/kestrel/hull.json` | Centred mesh in model space (nose +X), plus nozzle points |
| `packages/view3d/assets/kestrel/atlas.png` | Albedo, 512², occlusion already multiplied in |
| `packages/view3d/assets/kestrel/orm.png` | Roughness in G, metal in B |
| `packages/view3d/assets/kestrel/glow.png` | Emissive glass, bells and lights |

It is scaled to `hull.length` at runtime. The collision circle stays in `packages/content/data/ships.json`. See decision 064.

When a third-party asset is added, list it here with its source, author, license and the files it covers.
